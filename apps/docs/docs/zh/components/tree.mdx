# Tree 树形控件

`Tree` 接收一个用 `parentId` 互相链接的扁平 `TreeItem` 数组：`buildTree` 负责组装层级，
`visibleTreeEntries` 把已展开的分支拍平成行，整套键盘导航靠一个漫游 tab index 实现。选中值是
单个节点 id。

<ComponentMeta id="tree" />

## 何时使用

- 组织架构、部门选择、目录浏览、区域/资源清单这类真实有层级的数据。
- 以浏览为主、一次激活一个节点的场景：选中某部门后在别处展示其成员。
- 行内需要附加信息：16 px 图标、计数徽标、悬停描述。

## 何时不使用

- 表单里选一个值：同样的数据请包进 `Tree Select`，不要把裸树塞进表单。
- 在两组集合之间移动条目：用 `Transfer`。
- 按路径逐级收窄的选择（省/市/区）：`Cascader` 更合适。
- 需要边搜索边定位的深层级：`Tree` 没有过滤输入框，请自行预筛 `items`，或改用 `Tree Select`
  配合搜索框。

一旦传入 `expandedIds`，树即进入受控模式：点击箭头、切换选中都不再自行展开任何东西，所有变化通过
`onExpandedChange` 回报。若只需要固定的初始状态，去掉这两个属性、改用 `defaultExpanded` 即可。

## 设计指引

- 行是拍平的 `div`，缩进为 `paddingLeft: depth * 16 + 6px`，即每级 16 px。
- 有子级的行以 20 px（`size-5`）箭头按钮开头（`ChevronRight`，展开时 `rotate-90`）；叶子行渲染
  `aria-hidden` 的圆点占位（`size-1.5 bg-border`），保证标签对齐。
- `icon` 按 `size-4 text-muted-foreground` 呈现，`badge` 以 `text-xs text-muted-foreground` 排在
  行尾，`label` 通过 `min-w-0 flex-1 truncate` 截断。
- 选中行样式为 `bg-primary/10 font-medium text-accent-foreground`；悬停 `bg-accent`；聚焦描
  `border-ring` 加 `ring-[3px] ring-ring/50`。禁用行 `opacity-50` 且 `cursor-not-allowed`，点击
  与 Enter/空格均无效。
- 容器带 `select-none`；`description` 只通过行原生的 `title` 提示呈现。
- `buildTree` 对环安全：陷入父子环的记录会被断开并提升为根节点渲染，数据不会凭空消失。

## 无障碍

- 容器是 `role="tree"`，名称来自 `ariaLabel`；每行是 `role="treeitem"`，带 `aria-level`
  （深度 + 1）、`aria-selected`，且只有含子级的行才有 `aria-expanded`。
- 漫游焦点：同一时刻只有一个可见行的 `tabIndex` 为 0（初始为选中节点或第一行），其余为 -1。
  ↓/↑ 在可见行间移动，→ 展开折叠分支或进入第一个子级，← 收起展开的分支或跳到父级，Home/End
  跳到首/尾行，Enter/空格选中当前行。
- 箭头是真正的 `<button>`，可访问名称形如“展开 Engineering / 收起 Engineering”
  （`tabIndex={-1}`，点击时阻止冒泡，因此不会连带选中行）。
- 禁用行暴露 `aria-disabled`；树为空时以居中段落渲染 `emptyLabel`。

已知缺口：`badge` 文本拼进行 `aria-label` 时没有分隔符（读作“Platform7”），读屏会把名称和计数
连读——需要解释数字时请写进 `label`。另外没有首字母快速定位，子级列表也没有 `role="group"`
包裹。

## FAQ

**`parentId` 指向不存在或自身的节点会怎样？** `buildTree` 会把它们提升为根；构成环的节点被断开后
照常渲染，不会静默丢失。

**展开分支会顺带选中该节点吗？** 不会。箭头按钮阻止了事件冒泡，选中只来自点击行主体、Enter
或空格。

**为什么树不再自动展开到选中项？** 传入 `expandedIds` 即进入受控模式，祖先自动展开与
`defaultExpanded` 同时失效，展开集合完全由你维护。
