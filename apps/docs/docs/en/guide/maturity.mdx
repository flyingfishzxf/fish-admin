# Component maturity

`stable` means the component has a docs page, a live demo, at least one behavioural test, full
axe coverage and light/dark visual baselines. `beta` means at least one of those is missing; the
status is about evidence, not API quality.

## Promotion rule

A component is promoted only when `pnpm check:maturity` sees every evidence slot filled. Removing
a test, a baseline or the docs page drops it back to `beta` in the same pull request.
