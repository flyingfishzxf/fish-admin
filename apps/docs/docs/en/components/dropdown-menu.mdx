# Dropdown Menu

`Dropdown Menu` opens a list of actions from a trigger button. It wraps Radix DropdownMenu and ships
the item, checkbox item, radio item, submenu, label, separator and shortcut parts; the content
renders in a portal with the template's popover styling.

<ComponentMeta id="dropdown-menu" />

## When to use

- Row-level actions in a table, such as edit, duplicate and delete.
- A page header where secondary commands would otherwise crowd the primary button.
- View settings — independent toggles plus one single-choice option — that belong in one place.

## When not to use

- Navigating between pages: use links or `Sidebar`.
- A single, frequently used action: keep it a visible `Button`.
- Two to four mutually exclusive options that fit on screen: use `Segmented` or `Toggle Group`.
- Picking a value for a form field: use `Select` or `Combobox`.

## Design guidance

- Put the most common action first and the destructive one last, after a `DropdownMenuSeparator`.
- `variant="destructive"` only recolours the item and its icon; pair it with `Alert Dialog` when
  the action cannot be undone.
- Keep to one level of submenu: `DropdownMenuSub` nests further, but deep paths are hard to reach
  on touch and with the keyboard.
- Give the trigger a visible label, or an `aria-label` when it is icon-only.

## Accessibility

| Key           | Behavior                                                      |
| ------------- | ------------------------------------------------------------- |
| Enter / Space | Toggles the menu from the trigger; selects the focused item.  |
| Arrow Down    | Opens the menu from the trigger, then moves to the next item. |
| Arrow Up      | Moves focus to the previous item while the menu is open.      |
| Character key | Jumps to the next item whose text starts with that character. |
| Arrow Right   | On a submenu trigger, opens the submenu.                      |
| Arrow Left    | Inside a submenu, closes it and returns to the parent item.   |
| Escape        | Closes the menu and returns focus to the trigger.             |

The trigger exposes `aria-haspopup="menu"`, `aria-expanded` and `aria-controls`; the content is
labelled by the trigger. Closing with `Escape` or by selecting an item returns focus to the
trigger, while `Tab` is intercepted inside an open menu — press `Escape` before moving on.

Known gap: `DropdownMenuShortcut` is a plain `<span>` without `aria-keyshortcuts`, so a screen
reader reads the accelerator as ordinary item text.

## FAQ

**Why does the menu close when I toggle a checkbox?** Selecting any item closes the menu by
design. Keep it open with `onSelect={(event) => event.preventDefault()}` on the checkbox or radio
item if you want several changes in a row.

**Does `variant="destructive"` delete anything?** No. It changes the text and icon colour and the
focus background only; the action itself has to confirm or delete.

**Can the trigger live in a table cell?** Yes — pass `asChild` and the content is portalled out, so
a row's `overflow` never clips it.
