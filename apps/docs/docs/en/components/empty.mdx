# Empty

`Empty` composes a centred empty state: an optional icon tile, a title, a description and a content
row that holds your own actions. `variant="outline"` adds a dashed border, and every part is a plain
`div` you can style or replace.

<ComponentMeta id="empty" />

## When to use

- A list, table or board that has no items on first run, with a create action as the way out.
- Filters or a search that returned nothing, with a Clear filter action.
- A section the current role cannot see data in, with an explanation instead of a blank panel.

## When not to use

- Data is still loading: use `Skeleton` or `Spinner`, so the layout does not flash an empty state.
- A request failed: use `Alert` with the reason and a retry action.
- A short inline message inside a form or a field: plain text is enough.
- A full-page 404 or permission page: use a page-level layout with a heading and navigation.

## Design guidance

- The root is centred with a 24 px padding and a 24 px gap, then switches to 48 px padding from the
  `md` breakpoint; the radius is 8 px. `variant="outline"` adds a 1 px dashed `border-border` and no
  background.
- `EmptyHeader` caps at 384 px (`max-w-sm`) with an 8 px gap, so the title and description break at a
  readable measure. `EmptyContent` uses the same cap with a 16 px gap and full width.
- The icon variant of `EmptyMedia` is a 40 px tile with an 8 px radius, `bg-muted` and a muted glyph;
  icons render at 20 px. It carries an 8 px bottom margin inside the header.
- The title is 18 px medium with tight tracking; the description is 14 px muted, and links inside it
  are underlined and turn primary on hover.
- `Empty` has no size prop: for dense panels override `padding` and `gap` with `style` (the compact
  demo uses 20 px and 12 px) and drop the title to 16 px. There is also no `actions` prop — compose
  buttons inside `EmptyContent`.

## Accessibility

`Empty` renders no landmark, no live region and no interactive parts; its only semantics come from
the text you pass. The title is a `div`, not a heading, so heading navigation will not find it. The
icon tile renders whatever child you give it, and lucide icons are decorative by default, but an
`img` needs its own `alt`.

Known gap: because there is no `role="status"` or `aria-live`, an empty state that replaces a list
after a search or filter change is not announced. Add a live region with the result count, or move
focus to the title, when that change happens without a page reload.

## FAQ

**Does `Empty` accept actions?** Not as a prop. Render `Button`s inside `EmptyContent`; that wrapper
only centres and spaces them.

**How do I make it smaller?** There is no size prop. Override `padding`, `gap` and the title's
`fontSize` with `style` or `className`, as the compact demo does.

**Should the title be a heading?** The component renders a `div`. Pass `role="heading"` and
`aria-level` to `EmptyTitle`, or render your own heading, when the empty state anchors a page
section.
