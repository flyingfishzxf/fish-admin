# Checkbox

`Checkbox` is a Radix checkbox rendered as a button with a check indicator. It is controlled through
`checked` and `onCheckedChange`, accepts the indeterminate state, and paints invalid styling from
`aria-invalid`.

<ComponentMeta id="checkbox" />

## When to use

- A single boolean opt-in, such as enabling notifications or accepting terms.
- Several choices that are independent and can all be on at once.
- Table row selection, including an indeterminate header checkbox.

## When not to use

- A setting that applies immediately when flipped: use `Switch`.
- Mutually exclusive choices: use `Radio Group`.
- One choice from a long list: use `Select`.

## Design guidance

- The box is 16 px square with a 4 px radius; keep the label on one line and the description below it,
  as both demos do.
- Give every checkbox an `id` and a `Label` with a matching `htmlFor`; that is what supplies the
  accessible name.
- Treat a set as a set: wrap the options in a container with `role="group"` and an `aria-labelledby`
  (or a real fieldset with a legend) so the shared question is announced once.
- `checked` also accepts `'indeterminate'`, which is how a header checkbox shows a partial selection.

## Accessibility

| Key             | Behavior                                               |
| --------------- | ------------------------------------------------------ |
| Space           | Toggles the focused checkbox.                          |
| Tab / Shift+Tab | Moves focus to the next or previous focusable control. |

The root exposes `role="checkbox"` with `aria-checked`, including `mixed` for the indeterminate state.
The accessible name comes from the associated `Label`, and `aria-describedby` carries the hint text —
both demos point it at the description element.

Known gap: the component renders no label, description or error text, and there is no group wrapper;
`role="group"` plus a shared label stays your responsibility.

## FAQ

**Does `onCheckedChange` give me a boolean?** It gives `boolean | 'indeterminate'`. Compare with
`checked === true` to store a plain boolean, as the demos do.

**How do I build a select-all header?** Pass
`checked={someSelected ? 'indeterminate' : allSelected}` and handle the change on the header box.

**Can it submit a form?** Yes. Radix renders a hidden input, so a `<form>` submission includes the
value when the root has a `name`.
