# FishAdmin 2.1.0 — 设计系统深化

> 内部规划文档。各里程碑产出的用户可见文档必须在 `apps/docs/docs/en/` 与
> `apps/docs/docs/zh/` 同步提供英文与中文两份；client-side RBAC 不是安全边界这一
> 免责说明继续保留在 README 与权限相关页面。

- 基线：`v2.0.1`（`@fish-admin/react` 0.1.1）
- 计划日期：2026-11-02
- 目标版本：模板 `2.1.0`、`@fish-admin/react` `0.2.0`、`@fish-admin/tokens` `0.1.0`、
  `@fish-admin/docs` `0.2.0`
- 定位不变：**企业级中后台模板**。不引入后端、多租户或 SSO。

## 目标

2.0.x 把组件库做成了模板与文档站共用的设计边界，但 token 仍只是 React 包里的一个
CSS 文件。2.1.0 把设计系统本身变成可消费、可探索、可审计的产品：

1. **token 有独立契约** —— `@fish-admin/tokens` 用 JSON 描述 48 个 token，生成 CSS、
   Tailwind 入口、manifest 和浏览器可用的编辑器工具。
2. **文档站能玩设计系统** —— `/guide/theme-editor` 改色、看对比度、导出 CSS/JSON、
   分享 URL；`/guide/tokens` 是可检索的 token 参考。
3. **无障碍补齐高对比度与动效** —— `prefers-contrast: more`、`forced-colors: active`、
   动效 token 在 7 个签名组件落地，`prefers-reduced-motion` 逐组件处理。
4. **RTL 有可执行的差距清单** —— 审计结果进入文档，只做低风险机械修复，明确范围外。

## 现状（2026-11-02，`v2.0.1` 树）

| 项目        | 现值                                                           |
| ----------- | -------------------------------------------------------------- |
| 组件 / demo | 83 个注册组件 / 167 个双语 demo                                |

| 文档 guide  | installation / quick-start / theming                           |
| 动效        | Tailwind 默认时长散落在组件里                                  |

| CI          | quality / build / e2e / docs / docs-e2e / visual / docs-visual |

## 范围外

- 完整 RTL 支持、Vue 3 包、按组件拆分 CSS、Storybook / 在线沙盒。
- 模板 Settings 里的高对比度开关（本轮只有 OS 媒体查询 + 编辑器 preset）。
- 把 83 个组件全部迁移到动效 token（只改 7 个签名组件）。
- 主题编辑器持久化进模板；它只导出 CSS/JSON 和分享 URL。
